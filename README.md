# Site completo — Paula Sarmento

## Página inicial

`index.html` é o site principal da Paula, com apresentação, portfólio, Sobre mim e Mentoria Método Intuição.

O botão **Explorar o catálogo** abre `catalogo.html`. No catálogo, os botões **Conheça a artista** e **Sobre a artista e o Método Intuição** retornam ao site principal.

## Enviar ao GitHub

1. Extraia o ZIP no computador.
2. Envie o conteúdo extraído para a raiz do repositório: `index.html`, `catalogo.html`, a pasta `assets` completa, `photo-regions.json`, `.nojekyll` e este `README.md`. O arquivo `.nojekyll` pode aparecer oculto no computador.
3. Se o repositório já contém o catálogo antigo, substitua `index.html` por este novo arquivo e adicione os demais arquivos e imagens. Não envie apenas o ZIP, nem coloque tudo dentro de uma pasta extra no repositório.
4. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
5. Aguarde o GitHub concluir a publicação. O endereço principal abrirá o site da Paula; o catálogo ficará em `catalogo.html` no mesmo endereço.

## Arquivos

- `index.html`: site principal, com estilos e animações.
- `catalogo.html`: catálogo completo, com preços e ampliação das fotos.
- `assets/`: todas as imagens utilizadas nas duas páginas.
- `photo-regions.json`: referência dos enquadramentos do catálogo.
- `.nojekyll`: configuração para servir os arquivos estáticos no GitHub Pages.

Para conferir antes de enviar, abra `index.html` no navegador. Não é necessário instalar dependências ou compilar. As fontes do Google, Instagram e WhatsApp usam internet. As páginas e imagens estão incluídas neste pacote; a navegação entre o site principal e o catálogo usa caminhos relativos e não depende dos endereços anteriores do ChatGPT.
